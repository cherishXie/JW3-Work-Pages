## [0.7.0] — 2026-11-08

- 副本攻略新增独立查看入口，与任务执行共用逐首领速刷笔记，保存后同步更新。
- 自定义队伍独立管理，分为 5 人与 10 人队伍；同类型队伍中的角色互斥，两种类型可共用角色。支持队伍与角色搜索、分队名称、整队面板拖入、键盘选择和分页，模板配置不占用 CD；切回自动生成恢复原参与范围和逐队规则。
- 角色分析中的门派、当前心法定位可直接展开对应角色与账号名单，并查看或编辑角色档案；筛选只影响本模块。
- 网页保存将日期档案校验与序列化移到本地后台线程，及时显示保存状态，阻止重复提交，保留保存失败重试、撤销和原始数据保护。
- 更新提示支持悬停、键盘聚焦和手机点击查看本频道更新内容；网页更新显示真实下载与校验进度，复用校验一致的缓存资源、并行下载变更文件，失败时保留当前版本与本机数据。

## [0.6.0] — 2026-11-06

- 接入 JX3BOX 正式服物品资料与小时行情，在材料库存和库存估值中支持物品搜索、角色归属、持有数量录入和按角色当前区服查价；按 10,000 铜＝1 金换算，保存报价来源、时刻和样本量，超过 24 小时标记过期。绑定、无报价或角色转服后的不匹配报价不计估值，库存估值不作为已实现收入。
- JX3BOX 查询仅发送物品搜索词、物品 ID 与区服，不发送账号或角色名称。当前 GitHub Pages 来源受对方跨域授权限制，线上搜索和查价可能连接失败；保留来源链接、已有报价与手工登记。桌面版原有离线网络限制保持不变。
- 账号与角色保持单一工作台入口，共用左侧账号搜索、分页和选择，右侧以“账号角色列表”和“账号角色分析”两个 Tab 切换；切换保留查看范围，支持键盘操作和刷新恢复，不改变顶部全局筛选。
- 角色分析新增装备面板属性对比、装分分布与并列排名，以及按同名战斗场景隔离的门派心法 DPS 情景排名。缺失数据保留待补；DPS 采用参考值随目标装分线性调整的估算，不代表真实伤害或全服强度。
- 账号角色支持角色 JSON 导入与茗伊 SQLite 角色数据库读取，配置引导首页提供茗伊导入入口，保留导入预览、校验与原有数据保护。
- 修复桌面配置引导进入体验模式、退出体验模式后页面无响应的问题，只放行工作台自身入口导航；体验数据继续独立保存和清空。
- 桌面更新协议升级至 2，旧客户端需要安装一次新版桌面包以获得原生壳修复；新壳支持后续同协议资源更新，并拒绝旧协议缓存覆盖。业务数据保留。
- 保留五主题、1440 / 1024 / 390px 适配及大量角色的搜索、分页、选择保持、保存和恢复回归；main 稳定网页与 dev 开发网页继续独立部署。

## [0.4.0] — 2026-10-30

- 角色资料新增生活技艺等级、观测上限、专精状态与分支、熟练度、精进突破、备注和采集日期；角色卡片显示摘要，详情展开各项资料，支持技艺与专精名称搜索及备份恢复。参考“苍生铸世”官方生活技艺改造说明；未知资料留空，不套用角色等级压缩、旧版技艺上限或专精限制。
- 日常与副本安排支持外部团队参团，允许纯输出角色按自有席位参加，不再强制要求自有坦克、治疗或侠客；保留账号互斥、角色资格、区服与 CD 校验，整队掉落按自有席位分摊，不计外部成员收益与点卡。
- 顶部账号与角色范围改为复选筛选，支持搜索、分页、跨页保留和清空；账号内取并集，账号与角色范围取交集，同步应用于任务资格、资源、轨迹与收益统计。账号与角色模块内的选择、查看和编辑不再改变全局范围。
- 修复 PWA 缓存被清理、缺失或不可用时网页无法打开的问题：在线回退到网络资源，保留完整离线快照与多标签页版本隔离，并增加独立恢复入口，不删除本机业务数据。
- 更新状态改为浮动提示，区分发现新版、更新中、待处理、失败重试与当前版本；编辑和未保存排程仍会阻止资源切换，输入、保存与本机数据保留逻辑不变。
- 发布稳定网页及 Windows x64、macOS Apple Silicon / Intel 独立安装包，正式版统一为 0.4.0。开发版保留独立 dev 页面与预发布版本；正式发布验收网页、三平台构建与下载，日常 dev 仅验收网页。

## [0.2.1]

- 网页支持 PWA 安装及完整资源的离线打开，包含离线截图识别资源。
- 网页与新版 Electron 启动、返回前台和使用期间检查对应频道的新版本，提供立即更新、稍后及手动检查。
- 更新资源通过 SHA-256 校验后才切换；保留账号角色、本机数据与主题，编辑窗口或未保存排程会阻止切换。
- 多标签页分别固定资源版本，避免某个标签更新时替换另一标签正在使用的组件。
- Electron 的界面及业务资源可点击更新，失败或新版未能启动时回退；原生壳升级仍需安装对应系统安装包。
- 0.2.0 及更旧客户端需先安装一次 0.2.1 客户端，才能获得后续更新提示。main 稳定页面仍保持原版本。
